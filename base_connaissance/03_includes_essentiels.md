# Includes ESOPE essentiels (segments = structures des objets Gibiane)

`-INC NOM` insère ce fichier. Un `SEGMENT X ... ENDSEGMENT` déclare une structure allouée par `SEGINI X` dont les dimensions sont les variables citées. Commentaires conservés, espaces compactés.

      SEGMENT MRIGID

        INTEGER ICHOLE,IMGEO1,IMGEO2,IFORIG
        INTEGER ISUPEQ,JRCOND,JRDEPP,JRDEPD

	INTEGER JRSUP,IVECRI
      ENDSEGMENT
      POINTEUR RI1.MRIGID,RI2.MRIGID,RI3.MRIGID
      POINTEUR RI4.MRIGID,RI5.MRIGID,RI6.MRIGID
      SEGMENT XMATRI
        INTEGER SYMRE,SYMVER
        REAL*8 RE(NLIGRD,NLIGRP,NELRIG)

      POINTEUR XMATR1.XMATRI,XMATR2.XMATRI,XMATR3.XMATRI
      POINTEUR XMATR4.XMATRI,XMATR5.XMATRI,XMATR6.XMATRI

        CHARACTER*(LOCHPO) LISINC(NLIGRP),LISDUA(NLIGRD)

C IRIGEL(1,I) : POINTEUR SUR L'OBJET GEOMETRIE
C IRIGEL(2,I) : POINTEUR SUR UN OBJET GEOMETRIQUE (CAS FROTTEMENT)
C IRIGEL(3,I) : POINTEUR SUR LE SEGMENT DESCRIPTIF D'UNE

C IRIGEL(6,I) : NATURE DE LA RELATION DEFINISSANT LA RIGIDITE
C 0 EGALITE
C -1 INEGALITE INFERIEURE
C +1 INEGALITE SUPERIEURE
C +2 Mixte : CHANGEMENT DE PHASE / FROTTEMENT
C IRIGEL(7,1) : 0 LA MATRICE EST SYMETRIQUE
C : 1 LA MATRICE EST ANTISYMETRIQUE
C : 2 LA MATRICE NE POSSEDE PAS DE SYMETRIES
C IRIGEL(8,I) : 0 pas de dependance
C SYMRE : 0 LA MATRICE EST SYMETRIQUE
C : 1 LA MATRICE EST ANTISYMETRIQUE
C : 2 LA MATRICE NE POSSEDE PAS DE SYMETRIES
C RE(1,1,K ) : DEBUT DE VALEURS DE LA Kieme MATRICE ELEMENTAIRE
C LA MATRICE ELEMENTAIRE EST ORGANISEE COMME BON VOUS SEMBLE
C ELLE EST RECTANGULAIRE ET STOCKEE LIGNE PAR LIGNE

C LISINC(I)=INO : LA I EME INCONNUE PRIMAL DE LA MATRICE EST DE

C NOELED(I)=J : LA I EME INCONNUE DUALE DE LA MATRICE PORTE SUR
C LE J EME NOEUD DE L'ELEMENT .
C LISDUA(I)=INO : LA I EME INCONNUE DUALE DE LA MATRICE EST DE
C TYPE INO
C MTYMAT : TYPE DE LA MATRICE RIGIDITE OU MASSE
C ICHOLE : SI DIFFERENT DE ZERO EST EGAL AU POINTEUR
C SUR SEGMENT DE TYPE MMATRI(VOIR SMMATRI)
C CONTENANT LA MATRICE DEJA TRIANGULARISEE.
C ISUPEQ : POINTEUR EVENTUEL SUR UNE TABLE (UNILATERAL)
C IMGEO1 : UNE RESOLUTION A DEJA EU LIEU.POINTEUR SUR
C SUR UN TABLEAU CONTENANT LES POINTEURS DES
C OBJETS GEOMETRIQUES CREES.(TABLEAU DANS IMGEOD)
C IMGEO2 : POINTEUR SUR UN PROTOTYPE DU CHAMPOINT DUAL
C IFORIG : CORRESPOND A L'OPTION IFOUR (VOIR CCOPTIO)

C JRDEPD : pointeur sur une matrice de dependance duale
