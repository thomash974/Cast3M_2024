# Index des sources ESOPE

Une ligne par fichier `sources/*.eso` : `SOUS-PROGRAMME(args)` `⇐op:` opérateurs Gibiane qui l'appellent directement depuis PILOT, `—` rôle (commentaire d'en-tête), `→` routines appelées (hors API courante `ERREUR`, `LIROBJ`, `ECROBJ`, `ACTOBJ`, `LIRENT`…). `[nom]` = nom de fichier quand il diffère du sous-programme. `F:` fonction, `P:` programme. Suffixe `+` = liste d'appels tronquée à 8.
